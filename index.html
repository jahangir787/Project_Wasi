Project Wasi Debian Repository

About this repository

The software "Wasi" (Developed by Jahangir Hossain (jahangir.hossain.pust@gmail.com)) is a software for writing Bangla in Debian operating system and all other operating systems that is derived from Debian, like Ubuntu, Kali Linux, AntiX Linux and so on.  This software is named after Ujair Taimur Bin Jahangir Wasi (son of the developer of this software). The keyboard layout of Wasi is same as Avro phonetic keyboard Layout.

Installing Wasi

Add Wasi into your repository

Since Wasi is freshly build new software released on 13 November 2026, it is not currently accepted by official Debian repositories, but you can simply add this Github repository into your Linux system by just pasting the following command.


echo "deb [trusted=yes] https://jahangir787.github.io/Project_Wasi/ stable main" | sudo tee /etc/apt/sources.list.d/project-wasi.list

Update the repository

After adding the repository into your Linux system, just update the repository by pasting the following command.


sudo apt update

Run the installation command

To install wasi, now just simply type the following command and hit Enter key.


sudo apt install wasi

Launch Wasi

After the successful installation of Wasi, type the following command to run the program. Do not close the terminal from where you launched the Wasi program, but you may minimize it.


sudo wasi

Key-mapping in Wasi

To see the entire key-mapping for Wasi you can type either one of the following commands.


sudo wasi -h
sudo wasi --help

Write using Wasi

Open any Text editor and keep writing.

Language Mode Changing in Wasi

To switch between the keyboard mode from Bangla to English, just press SuperKey+SpaceBar together.

Reporting Problem

If you face any problem while using Wasi, just type "sudo wasi --help" or "sudo wasi -h" in the terminal and figure out the solution. If you cannot find the solution, you may directly e-mail me at jahangir.hossain.pust@gmail.com.
